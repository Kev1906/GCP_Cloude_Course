## Ejercicio 1: Dominando la Navegación de la Consola

### Ticket NAV-001: Convertirte en experto navegando la consola

**Solicitante:** Tú mismo (auto-asignado)
**Prioridad:** Alta
**Sprint:** Foundation Setup

**Contexto:**
La consola de GCP es tu herramienta principal. Necesitas saber encontrar servicios rápidamente y entender la estructura de navegación antes de empezar a crear recursos más complejos.

**Requisitos:**

1. **Explora el menú de navegación (☰):**
   - Identifica al menos **8 categorías** de servicios (ej: Compute, Storage, Big Data, Networking, Security, etc.)
   - Para cada categoría, anota **2 servicios específicos** que encuentres
   - Crea una tabla con esta información

2. **Usa la barra de búsqueda (🔍):**
   - Busca estos servicios y anota en qué categoría están:
     - Compute Engine
     - Cloud Storage
     - BigQuery
     - Cloud Functions
     - Pub/Sub
     - Cloud SQL
     - Kubernetes Engine
     - Cloud Run

3. **Personaliza tu experiencia:**
   - Fija (📌) al menos 3 servicios que crees que usarás frecuentemente
   - Toma nota de qué servicios fijaste y por qué

4. **Explora las notificaciones (🔔):**
   - ¿Tienes notificaciones pendientes?
   - ¿Qué tipo de información aparece ahí?

**Entregables:**
1. Tabla con 8 categorías y 2 servicios por categoría
2. Lista de los 8 servicios buscados con su categoría
3. Lista de servicios fijados con justificación
4. Descripción de las notificaciones que viste

**Criterios de evaluación:**
- ¿Puedes navegar la consola sin perderte?
- ¿Encontraste todos los servicios solicitados?
- ¿La tabla está completa y bien organizada?

## Ejercicio 2: Regiones y Zonas - Investigación

### Ticket GEO-001: Entender la geografía de GCP

**Solicitante:** Tú mismo (auto-asignado)
**Prioridad:** Alta
**Sprint:** Foundation Setup

**Contexto:**
DataMartX necesita decidir en qué regiones desplegar sus servicios. Antes de tomar decisiones, necesitas entender qué regiones están disponibles, dónde están ubicadas y cuáles son más relevantes para tu caso.

**Requisitos:**

1. **Investiga las regiones disponibles:**
   - Ve a: https://cloud.google.com/compute/docs/regions-zones
   - Identifica al menos **10 regiones** de GCP
   - Para cada región, anota:
     - Nombre de la región (ej: `us-central1`)
     - Ubicación geográfica (ej: Iowa, USA)
     - Número de zonas disponibles

2. **Regiones cercanas a ti:**
   - Identifica las 3 regiones más cercanas a tu ubicación actual
   - ¿Por qué son las más cercanas? (geografía)
   - ¿Cuántas zonas tiene cada una?

3. **Regiones para casos específicos:**
   - Si tu empresa tiene usuarios en España, ¿qué región usarías?
   - Si tu empresa tiene usuarios en México, ¿qué región usarías?
   - Si tu empresa tiene usuarios en Argentina, ¿qué región usarías?
   - Si tu empresa opera globalmente, ¿qué estrategia usarías?

4. **Compara costos:**
   - Ve a la calculadora: https://cloud.google.com/products/calculator
   - Compara el precio de una VM `e2-medium` (2 vCPU, 4GB RAM) en:
     - `us-central1` (Iowa)
     - `europe-west1` (Bélgica)
     - `southamerica-east1` (São Paulo)
   - ¿Cuál es la diferencia de precio? ¿Por qué crees que varía?

**Entregables:**
1. Tabla con 10 regiones, ubicación y número de zonas
2. Lista de las 3 regiones más cercanas a ti con justificación
3. Respuestas a las preguntas de regiones por país
4. Tabla comparativa de costos de VM en 3 regiones

**Criterios de evaluación:**
- ¿Entiendes la diferencia entre región y zona?
- ¿Puedes justificar la elección de regiones para diferentes casos?
- ¿Investigaste los costos correctamente?

## Ejercicio 3: Gestión de APIs

### Ticket API-001: Habilitar y gestionar APIs en tu proyecto

**Solicitante:** Tú mismo (auto-asignado)
**Prioridad:** Alta
**Sprint:** Foundation Setup

**Contexto:**
Antes de poder usar cualquier servicio de GCP, necesitas habilitar su API. Este ejercicio te dará práctica habilitando APIs y entendiendo qué servicios están activos en tu proyecto.

**Requisitos:**

1. **Verifica APIs actualmente habilitadas:**
   - Ve a: Menú hamburguesa (☰) → **APIs & Services** → **Library**
   - Haz clic en la pestaña **"ENABLED"**
   - Anota cuántas APIs tienes habilitadas actualmente
   - Lista las 5 APIs más importantes que ves habilitadas

2. **Habilita estas APIs (si no están habilitadas):**
   - Compute Engine API
   - Cloud Storage API
   - BigQuery API
   - Cloud SQL Admin API
   - Pub/Sub API
   - Cloud Functions API
   - Cloud Run API
   
   Para cada API:
   - Búscala en la Library
   - Haz clic en **"ENABLE"**
   - Espera confirmación
   - Anota cuánto tardó en habilitarse

3. **Explora una API en detalle:**
   - Elige **Compute Engine API**
   - Haz clic en **"MANAGE"** (Gestionar)
   - Explora las pestañas disponibles:
     - Overview (resumen)
     - Metrics (métricas de uso)
     - Quotas (límites de uso)
     - Credentials (credenciales)
   - ¿Qué información encuentras en cada pestaña?

4. **Investiga quotas:**
   - Dentro de Compute Engine API → **Quotas**
   - ¿Cuántas CPUs puedes tener en total?
   - ¿Cuántas VMs puedes crear por región?
   - ¿Qué pasa si necesitas más? (hint: busca "Edit quotas")

**Entregables:**
1. Número de APIs habilitadas antes del ejercicio
2. Lista de las 7 APIs que habilitaste con tiempo de habilitación
3. Descripción de las 4 pestañas de Compute Engine API
4. Respuestas sobre quotas de Compute Engine

**Criterios de evaluación:**
- ¿Pudiste habilitar todas las APIs solicitadas?
- ¿Entiendes la diferencia entre Library y Manage?
- ¿Investigaste las quotas correctamente?

## Ejercicio 4: Billing y Control de Costos

### Ticket BILL-001: Configurar control de costos profesional

**Solicitante:** Tú mismo (auto-asignado)
**Prioridad:** Crítica
**Sprint:** Foundation Setup

**Contexto:**
El control de costos es fundamental desde el día 1. DataMartX necesita asegurarse de que los equipos no gasten más de lo presupuestado. Vas a configurar un sistema de control de costos profesional.

**Requisitos:**

1. **Explora tu billing actual:**
   - Ve a: Menú hamburguesa (☰) → **Billing**
   - Responde:
     - ¿Cuánto crédito gratuito te queda?
     - ¿Cuánto has gastado este mes?
     - ¿Cuál es tu billing account ID?

2. **Crea un budget detallado:**
   - Ve a: Billing → **Budgets & alerts**
   - Crea un nuevo budget con estas características:
     - **Name:** `Curso GCP - Control Semanal`
     - **Budget type:** Current month
     - **Target amount:** $30 USD
     - **Thresholds:**
       - 50% ($15) → Email
       - 75% ($22.50) → Email
       - 100% ($30) → Email
     - **Actions:** None (por ahora)
   - Guarda el budget

3. **Analiza el desglose de costos:**
   - Ve a: Billing → **Cost breakdown**
   - Filtra por:
     - **Time range:** Last 30 days
     - **Group by:** SKU
   - Responde:
     - ¿Cuál es el servicio más caro que has usado?
     - ¿Hay costos que no esperabas?
     - ¿Cuánto has gastado en Cloud Storage?
     - ¿Cuánto has gastado en Compute Engine?

4. **Investiga el free tier:**
   - Ve a: https://cloud.google.com/free
   - Identifica al menos **5 servicios** que tienen free tier permanente
   - Para cada uno, anota:
     - Nombre del servicio
     - Límite gratuito (ej: 5GB de storage)
     - ¿Qué pasa si excedes el límite?

5. **Usa la calculadora de precios:**
   - Ve a: https://cloud.google.com/products/calculator
   - Estima el costo mensual de:
     - 1 VM `e2-medium` (2 vCPU, 4GB RAM) en `us-central1`
     - 100GB de Cloud Storage (Standard)
     - 1TB de datos procesados en BigQuery
   - Anota el total estimado

**Entregables:**
1. Resumen de tu billing actual (crédito, gasto, account ID)
2. Screenshot o descripción del budget creado
3. Análisis de costos (servicio más caro, costos inesperados)
4. Tabla con 5 servicios de free tier permanente
5. Estimación de costos de la calculadora

**Criterios de evaluación:**
- ¿El budget está configurado correctamente?
- ¿Entiendes la estructura de costos de GCP?
- ¿Investigaste el free tier correctamente?
- ¿Usaste la calculadora de precios?

## Tips del Mentor

1. **No te abrumes con tantas opciones.** GCP tiene cientos de servicios, pero solo usarás unos 20 regularmente.
2. **La búsqueda (🔍) es tu mejor amiga.** Más rápido que navegar por menús.
3. **Fija los servicios que uses frecuentemente.** Ahorra tiempo en el futuro.
4. **Elige regiones cercanas a tus usuarios.** La latencia importa más que el costo en producción.
5. **Configura budgets ANTES de crear recursos.** Es el error #1 de principiantes.
6. **Revisa billing diariamente.** 5 minutos cada mañana te ahorrarán sorpresas.
7. **Habilita solo las APIs que necesitas.** Menos es más en seguridad y organización.
8. **Investiga el free tier.** Muchos servicios tienen límites gratuitos generosos.
9. **Usa la calculadora de precios.** Siempre estima costos antes de crear recursos grandes.
10. **Si algo no funciona, lee el mensaje de error.** GCP da mensajes bastante descriptivos.

¡Buena suerte! Hoy estás construyendo las bases para trabajar eficientemente en GCP. Lo importante es entender dónde estás parado antes de empezar a construir.
